# Gemini KR IME fix

Gemini 웹 버전에서 한글을 쓸 때 생기는 불편을 고칩니다.

- **엔터 두 번 문제**: 한글 입력 중 엔터를 두 번 눌러야 전송되는 현상을 해결합니다.
- **깨진 굵은 글씨**: 답변에 `**텍스트**`처럼 별표가 그대로 보이는 부분을 굵은 글씨로 바꿉니다. (Gemini, NotebookLM)

# 설치 방법

1. [이곳을](https://github.com/luminen529/fix-kr-gemini/releases/latest/download/fix-kr-gemini.zip) 클릭하여 다운로드한 뒤 압축을 풉니다.
2. Chrome에서 `chrome://extensions`를 엽니다.
3. 오른쪽 위의 `개발자 모드`를 켭니다.
4. `압축해제된 확장 프로그램을 로드`를 클릭합니다.
5. 압축을 푼 폴더를 선택합니다.

이미 열려 있는 Gemini 탭에도 바로 적용되므로 새로고침할 필요가 없습니다.

# 주의

다운로드한 폴더를 삭제하면 Chrome에서 확장 프로그램을 로드할 수 없습니다.
