# Gemini KR IME fix

Gemini 웹 버전에서 한글을 쓸 때 생기는 불편을 고칩니다.

- **엔터 두 번**: 한글 입력 중 엔터를 두 번 눌러야 전송되는 현상을 해결합니다.
- **Bold 미적용**: 정상적으로 렌더링 되지 않은 Bold를 적용합니다. Gemini Web과 Notebook에서 적용됩니다. ex) `**텍스트**`

# 설치 방법

1. [이곳을](https://github.com/luminen529/fix-kr-gemini/releases/latest/download/fix-kr-gemini.zip) 클릭하여 다운로드한 뒤 압축을 해제합니다.
2. Chrome에서 `chrome://extensions`를 엽니다.
3. 오른쪽 위 `개발자 모드`를 켭니다.
4. `압축해제된 확장 프로그램을 로드`를 클릭합니다.
5. 압축을 푼 폴더를 선택합니다.

# 주의

다운로드한 폴더를 삭제하면 Chrome에서 확장 프로그램을 로드할 수 없습니다.
